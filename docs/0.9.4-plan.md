# 0.9.4 规划：设计指南语料、资源目录、设计入门

状态：**实现完成（本地，不推送）**

## 目标

把华为官方设计资源纳入 DwGuard 的**可追溯设计知识**，但不复制官方正文/资源文件。

## 1. 设计指南语料

- 源索引：`https://developer.huawei.com/consumer/cn/llms/docs-ux-design.txt`
- 脚本：`scripts/fetch-design-guide.mjs`
- 产物：`docs/design-guide/index.json`
- 每条记录：标题、章节、官方 URL、Markdown `sha256`、字节数、抓取日期、摘要、大纲、`DW-*` 规则映射
- **不保存**：Markdown 正文、图片、可下载设计资产
- 刷新：`node scripts/fetch-design-guide.mjs --concurrency 6`

## 2. 设计资源目录

- 产物：`docs/design-resources/index.json`
- link-only 卡片：官网入口、资源下载、设计指南索引、控件、图标/Symbol、模板/卡片、DevEco 工具链、无障碍焦点
- 每张卡声明 `license`、`licenseUrl`、`scope`、`usage`、`notFor`、`guideRefs`
- 不打包官方截图、图标、模板或安装包

## 3. 设计入门

- 机器可读：`docs/design-foundations.json`（7 个部分：原则/布局/色彩/字体/图标/动效/无障碍）
- 人读版：`docs/design-foundations.md`，由 `scripts/render-design-foundations.mjs` 生成
- 每条必须同时有：
  - 可测口径（`measure`）
  - 取证方式（`verify`）
  - 现有 `DW-AES-*` / `DW-A11Y-*` 规则绑定
  - 官方 `HW-UX-*` 引用
- 不新增“看起来更美”这类不可证伪条目。

## 验收

| ID | 判据 |
| --- | --- |
| DG-01 | `index.json` 覆盖 167 篇，sha256 全为 64 位 hex，抓取日期存在 |
| DG-02 | 不存正文/图片/资产字段，仅引用与摘要 |
| DR-01 | 每张资源卡都有 license、scope、usage、notFor |
| DR-02 | 所有 `guideRefs` 都能在指南索引中解析 |
| DF-01 | 每个设计入门条目都绑定有效规则，且有 measure/verify |
| DF-02 | Markdown 由 JSON 渲染，不手写漂移 |
| V-01 | 版本 0.9.4；测试/typecheck 通过；不 push/tag/publish |

## 不做

- 不抓取 `/design/resource/` 的二进制资源、图片或模板。
- 不把华为文档正文放进仓库。
- 不把设计建议冒充为官方验收规则；落地仍以 `dwguard_spec` / `dwguard_audit` 的可测规则为准。
