# 0.9.5 规划：章节级设计指南索引

状态：**实现完成（本地，不推送）**

## 目标

把 0.9.4 的“文档级摘要 + 前 8 个标题”升级为**章节级**索引：

- 每篇 `sections[]`；
- 每个 section 有标题路径、短摘要、官方锚点、所属 `HW-UX-*`；
- 每个 section 可映射到 `DW-AES-*` / `DW-A11Y-*`；
- 仍然不存正文、图片或资源文件；
- 对 `convenient-life` 强制断言 25 个小节全部覆盖。

## 数据结构

```json
{
  "id": "HW-UX-031-S04",
  "hwUxId": "HW-UX-031",
  "level": 3,
  "title": "店铺页",
  "headingPath": ["便捷生活类", "美食页面", "店铺页"],
  "summary": "……",
  "ruleRefs": ["DW-AES-07"],
  "mappingStatus": "direct",
  "anchor": "#%E5%BA%97%E9%93%BA%E9%A1%B5",
  "anchorUrl": "https://developer.huawei.com/.../convenient-life-...#%E5%BA%97...",
  "anchorKind": "heading-fragment",
  "contentStored": false
}
```

- `mappingStatus=direct`：标题/摘要直接命中规则；
- `descendant`：父级小节无正文，继承子小节规则并集；
- `unbound`：没有诚实的规则命中，不硬凑；
- 锚点是 Markdown 标题片段（`heading-fragment`），官方页面若使用不同 ID，以页面实际跳转为准。

## 实测

- 文档：167
- 小节：1,164
- `HW-UX-031` 便捷生活类：**25/25** 小节
- 该 25 节全部有至少一个 `DW-AES-*` / `DW-A11Y-*` 映射
- 无正文/图片/资源文件字段

## 验收

| ID | 判据 |
| --- | --- |
| S-01 | 每篇都有 `sections[]` |
| S-02 | 每个 section 有 headingPath、summary、anchor、hwUxId |
| S-03 | 每个 section 的 `ruleRefs` 只引用现有规则 |
| S-04 | `convenient-life` 的 25 个标题全部存在且不重复 |
| S-05 | 该 25 节全部有规则映射 |
| S-06 | 索引不存正文/图片/资产 |
| V-01 | 版本 0.9.5；测试/typecheck 通过；不 push/tag/publish |

## 不做

- 不把 199 个不适用的技术小节硬映射成审美规则；它们保留 `unbound`，避免假证据。
- 不复制官方正文或图片。
- 不推送远端。
