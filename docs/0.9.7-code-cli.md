# 0.9.7 — DevEco Code CLI zero-click path

## Prerequisite

    npm install -g @deveco/deveco-code
    deveco --version
    deveco auth login

The binary is called `deveco`, not `deveco-code`. It must be on PATH or set
`devecoCodePath`.

## Config

    executor: auto
    devecoCodePath: ''          # empty = APPDATA/npm/deveco.cmd or PATH
    codeProjectDir: ''          # empty = session workspace
    codeModel: ''               # provider/model, optional
    codeAgent: ''               # agent name, optional
    codeAuto: true              # pass --auto
    codeTimeoutMinutes: 45

## Tool

    dwguard_code action="run" dir="D:/project"
    dwguard_code action="status" id="code-1"
    dwguard_code action="stop" id="code-1"
    dwguard_code action="list"

`run` reads `tasks/goal-brief.md`, starts `deveco run --format json` in the
background, and writes JSON events to `artifacts/code-<n>/events.jsonl`. The
prompt only points the agent at the brief file, so long briefs never hit the
Windows command-line limit.

## Boundaries

- The job map lives in the DSH process; restarting DSH loses `status` for old
  runs, but the event log and `meta.json` remain on disk.
- Only one active job per project directory.
- `--auto` is convenient but approves non-denied tools; set `codeAuto: false`
  to keep interactive approval.
- The executor's own delivery is still not acceptance. Run `dwguard_scan`,
  `dwguard_audit` and independent device evidence afterwards.
