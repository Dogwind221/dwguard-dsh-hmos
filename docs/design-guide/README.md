# Huawei UX Design Guide Index

This directory is a **citation/summary index**, not a mirror of Huawei's docs.

- Source index: `https://developer.huawei.com/consumer/cn/llms/docs-ux-design.txt`
- Generated by: `node scripts/fetch-design-guide.mjs`
- Output: `index.json`
- Stored fields: title, section, source URL, sha256 of the fetched Markdown,
  byte count, fetch date, short summary, outline, `sections[]` and linked
  `DW-*` rules.
- Each section stores its heading path, level, short summary, anchor fragment,
  `hwUxId`, rule refs and `mappingStatus` (`direct` / `descendant` / `unbound`).
  A section's body, image or asset is never stored.
- **Not stored:** full Markdown bodies, images, downloadable design assets or
  binary files.

The current index has 167 documents and 1,164 subsections. The
`convenient-life` document (`HW-UX-031`) has all 25 subsection headings; its
25/25 rule mapping is asserted in `tests/design-knowledge.test.mjs`.

## Refresh

```powershell
node scripts/fetch-design-guide.mjs --concurrency 6
```

The index is intentionally regenerated rather than edited by hand. A summary
is a citation aid; the official page is authoritative.
