# 0.8.0 真机/CLI 验证记录

> 环境：Windows、`devecocli 1.3.10`、Pura 90 模拟器（`127.0.0.1:5555`，HarmonyOS 6.1.1(24)）。
> 没有物理手机，所以这是**模拟器**验证，不是物理真机；结论按“CLI + 设备链可用”记录。

## 1. 生成工程与签名

```text
devecocli create --project-path ... --app-name PipelineProbe24 \
  --bundle-name com.example.pipelineprobe24 --device-types phone --api-level 24
devecocli signature generate
devecocli build
```

结果：

- `signature generate` 成功，写出 `build-profile.json5` 的 signing config；
- 默认 API 26 工程安装到 OS 24 模拟器失败：
  `code:9568297 · install failed due to older sdk version in the device`；
- 重建为 **API 24** 后 `run` 成功，输出 `Smoke: PASS`。

## 2. 截图 / 布局参数

```text
devecocli ui screenshot --device "Pura 90" --path <dir>/shot.png
devecocli ui layout --device "Pura 90" --format json --mode full
```

结果：

- screenshot 成功，1320×2856 PNG，sha256
  `8AC2790B7BE104DDC4ABC275C8AF4872E7D1CAD2B53101A8ED4C99DEFB0797D8`；
- layout 成功，但 stdout 末尾追加了
  `New docs version ...`，直接 `JSON.parse(stdout)` 会失败；
  已改为 `extractJsonText()` 只取 JSON 主体，再写 `layout.json`。

## 3. Pipeline 实测

在 API 24 工程上运行 `dwguard_deveco action:"pipeline"`：

- 5 步全部 exit 0：`sign → build → run → screenshot → layout`；
- 证据：`.shared/artifacts/deveco-2/pipeline.json` + `layout.json`；
- 发现并修复：
  1. **顺序**：`signature generate` 写入签名配置后需要重新 build，原 `build→sign` 会留下未签名产物；改为 `sign→build`；
  2. **设备名含空格**：Node `spawn(..., {shell:true})` 不自动加引号，`--device Pura 90` 变成两个参数；已加 `quoteShellArg`；
  3. **layout notice**：见上，`extractJsonText` 修复；
  4. **API level 与设备 OS 不匹配**：CLI 报错清晰，但需要在环境 SOP 中提前检查。

## 4. hdc fallback 实测

```text
hdc shell snapshot_display -f /data/local/tmp/pipeline.jpeg
hdc file recv /data/local/tmp/pipeline.jpeg <local>.jpeg
hdc shell uitest dumpLayout -p /data/local/tmp/layout.json
hdc file recv /data/local/tmp/layout.json <local>.json
```

结果：两条链均 exit 0，截图 76888 B、布局树 27366 B；已接入
`devecocli → (deveco-mcp) → hdc+hvigor` 的自动 fallback 计划。

## 5. 限制

- 这是模拟器；物理设备的签名/驱动/性能仍需单独验收；
- `deveco-mcp` 的实际命令接口未在本机验证，默认只作为可配置 tier；
- hdc fallback 的 `run` 需要调用方提供 signed HAP、bundleName、ability；
- `hvigor` build fallback 的工程参数在不同 DevEco 版本可能不同，需按项目覆盖。
