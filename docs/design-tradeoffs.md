# 设计取舍：10 个决定

> 这份文档解释「为什么这样设计」，不是功能清单。主线只有一句：**证据优先、离线优先、可回退、不要用漂亮结论替代可复核事实。**

| # | 决定 | 为什么 | 放弃了什么 / 边界 |
| --- | --- | --- | --- |
| 1 | 设计包用 `schemaVersion: 2` | v1 是内部库格式，带内部 id/status，不能安全跨项目搬。v2 改成 inbox 兼容的卡片 + `cardFiles` + 预览 + why/cost，才可导出、迁移、再导入。 | 放弃“内部结构直接复制给别人”。v1 仍可读但降为 `draft`；没有审计/确认的包不能升为 paradigm。这里的 v2 是**设计包 schema**，不是任务包或 outbox 协议。 |
| 2 | 状态落盘到 `.shared/` | 会话会断、上下文会丢、执行可能超时。`state.json`、`harness/run.json`、`queue.json` 让新会话能 resume、看门狗能发现卡住、调度器能 claim/lease。 | 放弃“只放内存/只靠聊天记录”。边界是单机文件锁：不承诺多机一致、多租户、高可用；锁坏了要能重建，不把它当数据库。 |
| 3 | 设计检索默认 BM25，不默认向量 | 本地、离线、确定、零 API key、可写测试；同一个查询今天和明天结果一致。语义检索只在配置了 embedding 端点时作为 opt-in。 | 放弃“默认 semantic/CLIP 更聪明”的叙事。边界：词面不重合的召回弱；hybrid 失败要有显式 fallback，不能把相似度说成语义理解。 |
| 4 | 拒绝自评作为验收 | 执行者说“已完成”不是证据。must+pass 必须有独立取得的证据文件/结构化 actual；缺证据就是 `unverified`，不是 pass。Audit 由外部步骤做，不采信 DevEco 自验。 | 放弃“截图一张 + 文字说通过”的便利。边界：证据仍可能造假，自述标记只是启发式；所以还要哈希、manifest、抽样复核，不能声称绝对真实。 |
| 5 | 四维验收，不合成一个总分 | 功能、审美、性能、无障碍不能互相抵扣。一个高分不能掩盖无障碍失败；“架构”只进派发前预审，不做第五个验收维度。 | 放弃“85 分 = 可发布”的单指标。边界：四维仍可能漏项；所以用 must、覆盖率、未验证清单和返工单，而不是用总分掩盖缺口。 |
| 6 | 证据包不可变 + 可选类型化证据 | 证据必须能重算：manifest 记录 sha256/字节数，`evidenceRefs` 标类型；`requiredEvidence` 缺失时 pass 降级。字段可选，旧任务包保持原行为。 | 放弃“有文件路径就算有证据”，也放弃“一上来强制所有旧包补新字段”。边界：未声明 `requiredEvidence` 的旧包仍按旧规则；checker 只读，不替代最终 gate。 |
| 7 | 设备矩阵按宿主内存/屏幕族做，不承诺全物理矩阵 | 16GB 以下强制单机，矩阵只覆盖声明的屏幕族；每设备 lease 防止并发抢设备；无物理设备就 `blocked`。 | 放弃“所有设备都测过”的宣传。边界：模拟器通过不等于物理通过；`--require-physical` 必须 exit 2，不用截图伪造。 |
| 8 | IDE 优先，CLI 只做批处理/无视觉必须项 | DevEco 的 UI、截图、布局树证据在 IDE/设备链路上更可靠；CLI 适合 build/批量/无视觉回归。 | 放弃“一个 CLI 包打天下”。边界：CLI 不伪造 UI 证据；路由错误要显式提示，不能让执行者自己改判据。 |
| 9 | 设计知识只存引用/摘要，link-only | 官方正文/图片/图标/模板有版权和体积问题；索引保存 URL、sha256、抓取日期、短摘要、章节和规则映射，足够定位与复核。 | 放弃“把官方文档镜像进仓库”。边界：摘要不是官方原文，官方更新要重抓；167 篇/1,164 节只是当前快照，不是完整设计教育。 |
| 10 | 0.9.9 不发布，1.0.0 才做公开基线 | 0.9.9 是发布候选，先验证 coverage、benchmark、并发、干净安装；1.0.0 才承诺“其他开发者可安装试用”。 | 放弃“先发一个版本再说”的节奏。边界：1.0.0 仍不是生产级，没有 SLA/监控/备份/on-call；市场目录刷新也有延迟。 |

## 一句话

这些选择都在同一个方向上：**宁可少承诺一点，也要让结论能被下一个人复核。**  
如果以后要加“更智能”的能力，先回答三个问题：证据是什么、失败怎么退回、旧数据怎么办；答不上来就不进主路径。
