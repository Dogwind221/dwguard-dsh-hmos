# 1.0.0 — first public baseline (P1)

Status: **P1 evidence collected; public-release checks pending**.

1.0.0 is the first baseline intended for other developers. It is not a claim of
production operations, multi-tenant scale or physical-device coverage.

## Current evidence (2026-11-16)

- coverage: 86.92% line / 72.48% branch / 86.56% funcs
- scan benchmark: 40 files, p50 18.07ms, p95 19.51ms
- `npm test`: 191/191
- clean temporary profile: install 0.9.9 tarball + boot `CLEAN-INSTALL-0.9.9`
- publish gate: 202 files, version 0.9.9

The evidence is for the 0.9.9 candidate, not a published 1.0.0.

## P1 scope

### Quality evidence

- [x] TypeScript coverage report (`node --test --experimental-test-coverage`
      or c8), baseline recorded; no arbitrary 80% gate yet.
- [x] One real benchmark for scan / rules / design search, with p50/p95/max and
      a baseline; no unrelated microbenchmarks.
- [x] Concurrency stress tests:
  - state lock / CAS
  - queue claim / lease expiry
  - bridge idempotency
  - device lease
- [x] AI review closure: the three 0.9.8 findings fixed, regressions green,
      review document updated from “WIP” to verified.

  Local: typecheck + 191/191 green; CI still needs the new commit.

### Public usability

- [x] Clean-machine quickstart verified end to end (temporary profile, local
      tarball; npm-installed release still pending).

- [x] Known limitations published in the README and package.
- [ ] Install / upgrade / uninstall docs verified against the published package.
- [ ] Marketplace catalog card has icon, accurate description and current version.
- [ ] `doctor` gives actionable errors for missing DSH/DevEco/hdc/device.

### Honesty and boundaries

- [x] Design guides remain citation/summary-only (no official body/assets).
- [ ] 1.0.0 release notes state: self-use scale, no production ops/SLO/on-call.
- [ ] Recheck cordis/schemastery if DSH 0.2.3 appears.

### Release

- [ ] Version 1.0.0 only after all above.

## Not in 1.0.0

- Multi-tenant hosting
- Production monitoring/backup/SLO/on-call
- Physical-device matrix for all families
- Guaranteed CLIP endpoint availability
- Go runtime checks (`go test`, `go vet`, `-race`) — this is a TypeScript plugin
