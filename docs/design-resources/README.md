# Huawei Design Resource Catalog

Link-only cards for official HarmonyOS design resources and toolchain. No
official asset is copied into this repository.

- `index.json` — machine-readable cards.
- Each card declares `license`, `licenseUrl`, `scope`, `usage`, `notFor`, and
  the design-guide references it is based on.
- Downloads remain subject to Huawei's site terms and per-asset terms.
- Verify a card before using it as evidence; a link is not a license.
